How it works: the first time you click Backup Now, the browser’s folder picker opens. Select a folder once — the backup file (for example B2B-Backup-2026-10-28_14-46-30.json) is saved directly in that folder, and later manual and auto backups use the same folder. To use a different folder, click Select / Change Folder and pick a new one.

Notes: folder backup works in Chrome or Edge on a computer. If the browser asks permission to save files in the folder, allow it. After a page refresh the browser may ask once to confirm folder access — click Backup Now to allow it again, then auto backup resumes. Later, press Restore to bring back Inbox, Orders, Payments, Events, People and Signal state from a backup file.

bKash Personal Numbers

6 PAGES
Use the bKash Personal number only. This is not the customer support number — the customer support number must never be used as the bKash number, and it cannot be saved here. When you press Save for a Page, the backend saves that number as text for that Page and uses it in that Page's customer payment messages.

Enter the full 11-digit number starting with 0 (for example 01XXXXXXXXX). The number is saved as text, so the leading zero is kept. Each Page has its own number and its own Save button — changing one Page does not change the others.
